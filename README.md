# ThumbPick

블로그 썸네일을 빠르게 만드는 브라우저 기반 웹 도구입니다.

## 🔗 바로가기

- **실제 사이트:** https://zerosynn.github.io/ThumbPick/
- **Smart 자동 생성기:** https://zerosynn.github.io/ThumbPick/smart.html
- **랜딩페이지:** https://zerosynn.github.io/ThumbPick/landing.html
- **기본 제작기:** https://zerosynn.github.io/ThumbPick/index.html

> 제목 하나로 썸네일 문구를 추천하고, 여러 디자인을 빠르게 비교해 저장할 수 있습니다.

## 현재 기능

- `index.html` — 기본 썸네일 제작기
- `smart.html` — 제목 1개 → 썸네일 문구 3개 추천 → 디자인 4안 자동 생성
- `landing.html` — 서비스 소개 및 제작 방식 선택
- 1080×1080 PNG/JPG 저장
- 사진 업로드 및 브라우저 로컬 처리
- 카테고리별 배지와 디자인 적용

## Smart 흐름

1. 블로그 제목 입력
2. 썸네일용 짧은 문구 3개 추천
3. 추천 문구 선택
4. 에디토리얼 / 볼드 / 다크 / 클린 4안 동시 생성
5. 개별 저장 또는 4개 모두 저장

현재 문구 추천은 외부 API 비용이 들지 않는 규칙 기반 Smart Copy Beta입니다. 향후 AI API를 연결할 수 있도록 UI와 흐름을 분리해두었습니다.

## 수익화 확장안

Free: 기본 템플릿, 스마트 문구 기본 추천, 이미지 저장

Pro 예정: 프리미엄 템플릿 50+, AI 후킹 문구, 브랜드 프리셋, 대량 생성, 광고 제거

> ThumbPick은 특정 포털의 공식 서비스가 아닌 독립적인 콘텐츠 제작 도구입니다.
