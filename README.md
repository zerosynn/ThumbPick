# ThumbPick

블로그 콘텐츠 제작자를 위한 브라우저 기반 썸네일 제작기입니다.

## 현재 MVP

- 랜딩 페이지 (`index.html`)
- 썸네일 에디터 (`app.html`)
- 1080×1080 PNG/JPG 다운로드
- 사진 업로드 및 로컬 브라우저 처리
- 6종 기본 템플릿
- 컬러, 폰트, 정렬, 글자 크기 조절
- 규칙 기반 스마트 썸네일 문구 3개 추천
- 모바일 반응형 UI
- Pro 기능 및 광고 영역을 위한 UI 자리 마련

## 수익화 가설

### Free
- 기본 템플릿
- 기본 스마트 문구 추천
- PNG/JPG 다운로드
- 광고 노출

### Pro (초기 가설: 월 4,900원)
- 프리미엄 템플릿 50+
- LLM 기반 제목/후킹 문구 추천
- 브랜드 컬러/폰트 프리셋
- 여러 썸네일 일괄 생성
- 광고 제거

가격은 실제 사용자 반응과 전환율을 확인한 뒤 확정합니다.

## 다음 개발 우선순위

1. GitHub Pages 또는 별도 호스팅으로 공개 베타 배포
2. 사용 이벤트 측정: 제작 시작, 템플릿 선택, 다운로드
3. SEO용 콘텐츠/도구 랜딩 페이지 추가
4. 템플릿 20~30종으로 확장
5. 이메일 기반 출시 알림/대기자 수집
6. AI API 연동 시 서버리스 백엔드 추가 (API 키를 프론트엔드에 노출하지 않기)
7. 로그인, 저장 프로젝트, Pro 권한
8. 국내 PG 연동 및 결제/환불/약관/개인정보 처리 체계 구축
9. 광고 네트워크 심사 및 배치 테스트

## 운영 원칙

- 특정 포털의 공식 서비스 또는 제휴 서비스로 오인시키지 않습니다.
- 제3자 상표는 설명적 문맥에서만 사용하고 서비스 브랜드에는 사용하지 않습니다.
- 사용자 업로드 이미지는 MVP에서 서버로 전송하지 않습니다.
- 실제 AI API 도입 시 API 키는 서버 환경변수로 관리합니다.
- 결제 도입 전 이용약관, 개인정보처리방침, 환불정책, 사업자 관련 요건을 확인합니다.
